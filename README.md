# Todo 타이머 - 집중 관리 프로그램

Java Swing으로 구현한 개인 시간 관리 데스크톱 애플리케이션입니다. 단순한 할 일 목록에 시간 측정 기능을 더하고, 뽀모도로 기법과 집중 모드(다른 작업 방지)를 결합하여 실제로 작업 시간을 관리할 수 있도록 만들었습니다.

## 주요 기능

### 1. 할 일 목록 관리
- 텍스트 입력 후 추가 버튼 또는 Enter 키로 할 일 등록
- 항목 선택 후 삭제 가능 (타이머 실행 중에는 삭제 불가)
- 완료 처리 토글 기능
- 각 항목에 누적 작업 시간(시:분:초) 표시

### 2. 타이머 기능
- `javax.swing.Timer`를 이용해 1초 단위로 시간 측정
- 시작 / 정지 / 초기화 버튼으로 제어
- 선택한 할 일에 시간이 자동으로 누적 저장됨

### 3. 뽀모도로 모드
- 집중 시간(10~90분)과 휴식 시간(3~15분)을 직접 선택 가능
- 집중 시간이 끝나면 경고음과 함께 자동으로 휴식 단계로 전환
- 휴식이 끝나면 다음 라운드 진행 여부를 선택
- 진행 바로 현재 단계의 진행률을 시각적으로 표시
- 라운드 횟수 카운트

### 4. 집중 모드 (Focus Lock)
- 타이머 실행 중 다른 창으로 전환하는 것을 막기 위한 기능
- 전체화면 오버레이 창으로 화면을 가리고 현재 작업명과 경과 시간을 표시
- 다른 창으로 포커스가 이동하면(이탈) 경고음 재생 + 강제로 창을 다시 앞으로 가져옴
- 이탈 횟수를 누적 카운트하여 표시
- 타이머 종료 시 이탈 횟수 기반으로 집중도(%)와 등급을 보여주는 리포트 제공
- 오버레이 화면의 정지 버튼 또는 ESC 키로 언제든 종료 가능

### 5. 데이터 자동 저장 / 불러오기
- 프로그램 종료 시 `todo_data.txt` 파일에 자동 저장
- 다시 실행하면 자동으로 이전 데이터를 불러옴
- 저장되는 정보: 할 일 목록, 누적 시간, 완료 여부, 집중 모드 ON/OFF 상태, 뽀모도로 ON/OFF 상태, 집중/휴식 시간 설정
- 같은 날 재실행: 모든 데이터 그대로 복원
- 날짜가 바뀌어 재실행: 할 일 목록과 설정은 유지되지만 누적 시간은 초기화 (새로운 하루 시작)

## 파일 구성

| 파일 | 설명 |
|------|------|
| `TodoItem.java` | 할 일 데이터 모델 (이름, 누적 시간, 완료 여부) |
| `CBtn.java` | 커스텀 버튼 컴포넌트. Windows 환경에서 `JButton`/`JToggleButton`의 배경색과 글씨색이 시스템에 의해 강제로 덮어써지는 문제를 해결하기 위해 `JPanel`을 상속해 직접 그리는 방식으로 구현 |
| `FocusOverlay.java` | 집중 모드 시 화면을 가리는 전체화면 오버레이 창 (`JDialog` 기반) |
| `TodoTimerApp.java` | 메인 애플리케이션. 전체 UI 구성과 이벤트 처리, 타이머 로직, 데이터 저장/불러오기를 총괄하는 메인 클래스 |

## 실행 방법

### 요구 사항
- Java 8 이상 (JDK)

### 컴파일
```bash
javac -encoding UTF-8 -source 8 -target 8 *.java
```

### 실행
```bash
java TodoTimerApp
```

> 한글이 깨지는 경우 컴파일 시 `-encoding UTF-8` 옵션이 빠지지 않았는지 확인하세요.
> 컴파일과 실행에 사용하는 Java 버전이 다르면(`UnsupportedClassVersionError`) `-source`, `-target` 옵션으로 버전을 맞춰주세요.

## 사용 흐름

1. 할 일을 입력하고 추가
2. 필요하다면 뽀모도로 모드와 집중 모드, 집중/휴식 시간을 설정
3. 목록에서 작업할 항목을 선택 후 시작 버튼 클릭
4. 집중 모드가 켜져 있다면 오버레이 화면이 나타나고, 다른 창으로 전환 시 경고음과 함께 강제로 복귀됨
5. 정지 버튼(또는 오버레이의 정지 버튼/ESC)으로 작업 종료
6. 작업이 끝나면 완료 버튼으로 상태 변경 가능
7. 프로그램을 종료하면 모든 데이터가 자동으로 저장됨


## 사용 기술

- Java Swing (`JFrame`, `JDialog`, `JList`, `JProgressBar` 등)
- `javax.swing.Timer` 기반 타이머
- `javax.sound.sampled` (Java Sound API)를 이용한 직접 비프음 생성
- `java.io` 기반 파일 입출력 (UTF-8 인코딩)
- `java.time.LocalDate`를 이용한 날짜 비교
